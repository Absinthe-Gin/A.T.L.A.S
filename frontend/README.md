# Frontend — AI Personal Assistant

React + TypeScript + Vite + Tailwind CSS.

Kiến trúc và quy ước: [docs/architecture/frontend-architecture.md](../docs/architecture/frontend-architecture.md).

## Lệnh

Chạy trong thư mục `frontend/`.

| Mục đích | Lệnh |
| --- | --- |
| Cài dependency | `npm install` |
| Tạo file cấu hình | Sao chép `.env.example` thành `.env` |
| Chạy dev server | `npm run dev` |
| Chạy test | `npm run test` |
| Lint | `npm run lint` |
| Type check và build | `npm run build` |

Dev server chạy tại `http://localhost:5710` và gọi Backend theo `VITE_API_BASE_URL`.
